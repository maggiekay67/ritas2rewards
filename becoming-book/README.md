# Becoming — M.E.

Landing page for the poetry collection *Becoming*. Single self-contained
`index.html` (fonts loaded from Google Fonts, cover image inlined as a data
URI) — no build step required.

## Deploy on Vercel

1. Go to https://vercel.com/new and import the `maggiekay67/ritas2rewards` repo.
2. Under **Root Directory**, click "Edit" and select `becoming-book`.
3. Framework Preset: **Other** (static site, no build command needed).
4. Deploy.

To use a custom domain, add it under the new Vercel project's
**Settings → Domains** once the first deploy succeeds.
